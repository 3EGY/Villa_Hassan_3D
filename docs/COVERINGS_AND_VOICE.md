# Villa Hassan · الشتر والستائر والتحكم الصوتي — v2.8

> إصدار محاكاة للدور الأول. **لا يوجد اتصال بأجهزة كهربائية حقيقية**، أو سيرفر للتحكم عند إغلاق المتصفح.

## التوزيع

مرجع المواقع الوحيد هو `js/data/coverings-config.js`؛ مرجع مقاسات الشبابيك هو `js/data/window-config.js`، فلا تكرر المقاسات. يوجد **5 شترات** تستهدف الفتحات W1-W2 (غرفة النوم الرئيسية)، W3 (الغرفة اليسرى)، W4 (الصالة العائلية)، W6 وW7 (الغرفة اليمنى). شباك حمام الضيوف W5 مستبعد.

الستائر **5 وحدات ضمن 4 مجموعات مكانية**:

| المجموعة | الموضع | المعرّف |
| --- | --- | --- |
| شباك غرفة النوم الرئيسية | W1-W2 | `curtain_master` |
| دخول التراس من غرفة النوم | الباب الزجاجي السحاب عند x=599, y=301، بعرض 211 سم | `curtain_terrace` |
| الغرفة اليمنى | W6 وW7، موتور لكل شباك | `curtain_right_left` + `curtain_right_right` |
| الغرفة اليسرى | W3 | `curtain_left` |

إحداثيات الأبواب والشبابيك مأخوذة من الرسم الموجود في `js/model/architecture.js`؛ الباب السحاب هو فتحة مستقلة عن الستة شبابيك المعتمدة.

## طريقة التحكم

- في المشهد توجد أيقونة شباك (شتر) وأيقونة ستارة قرب كل فتحة ذات صلة. تختفي الأيقونات في المشهد العام وتظهر فقط عند اختيار الغرفة، مثل اللمبات. ويمكن إخفاؤها من إعدادات الطبقات بشكل مستقل.
- بالضغط على الأيقونة تظهر دائرة التحكم: **فتح** = 100%، **إغلاق** = 0%، **تحديد المستوى** يُظهر قوس تحكم بالسحب والفأرة أو اللمس. التغيير يرسل `setPosition` إلى `VillaDevices`، ويظهر بتحريك الشتر الرأسي أو ضلفتي الستارة على المجسم تدريجيًا.
- أزرار الجانب الأيمن فوق أيقونة الإضاءة: أيقونة الشتر وأيقونة الستائر، وفوقهما ميكروفون. قائمة كل نوع تشمل فتح الكل وإغلاق الكل ووضع النهار (فتح الجميع) ووضع الليل (إغلاق الجميع) والتلقائي؛ يمكن التحكم بكل فتحة بصورة منفصلة، ولستارتي الغرفة اليمنى زر جماعي إضافي.
- حالات نسب الفتح محفوظة في `localStorage` داخل نفس المتصفح.

**مهم:** تجسيد القماش والشرائح هو تصميم توضيحي لمحاكاة الحركة، وليس نموذج تصنيع نهائي للمحركات أو اتجاه فتح الستائر. يتكيف الطول المعروض مع مستوى الحوائط في نمط القطاع المعماري، ولا يغير أبعاد فتحات المبنى نفسها.

## الأوضاع والتلقائي

لكل من الشتر والستائر جدولة **مستقلة**؛ يختار المستخدم وقت فتح ووقت إغلاق مختلفين بصيغة `HH:mm`. الحقول الافتراضية: فتح 07:00 وإغلاق 20:00؛ الوضع التلقائي **غير مفعّل افتراضيًا**. عند الحفظ والتفعيل يطبق المتصفح حالة الفترة الجارية، ويتابع تبدل الفترة طالما الصفحة نشطة. إذا تم فتحها مجددًا في وقت لاحق فسيعيد حساب الفترة الحالية. «فتح الكل» و«إغلاق الكل» و«وضع النهار/الليل» تلغي التلقائي لذلك النوع وتطبّق أمرًا يدويًا.

الوقت هو **التوقيت المحلي للمتصفح**، لا توقيت خادم أو موقع آخر. لا يستمر تنفيذ الجدولة عند إغلاق الصفحة؛ يمكن أن يقلّ تواتر التوقيت عندما تكون الصفحة بالخلفية ويُستعاد عند الرجوع إليها. للتشغيل الفعلي دون صفحة مفتوحة، ينبغي نقل الجدولة إلى متحكم منزل أو خادم آمن داخل شبكة الفيلا.

## الأوامر الصوتية

الميكروفون يبدأ **مباشرة بعد الضغط على أيقونة الميكروفون** (أو «بدء الاستماع» في القائمة الاحتياطية)، ويستعمل `SpeechRecognition` أو `webkitSpeechRecognition` في المتصفح إذا كانت متاحة. يُضبط الإدخال على `ar-EG`، وتُقبل عدة صياغات عامية مصرية وأرقام عربية. يعرض الكلام في منتصف الشاشة مع مؤشر متحرك فوق شريط التنقل؛ ينفّذ الأمر عند انتهاء الكلام/السكوت. تظهر «أعد المحاولة» عند عدم فهمه، وبعد 3 محاولات تُفتح القائمة الاحتياطية تلقائيًا. ويمكن فتح القائمة دائمًا من إعدادات «الطبقات والإضاءة». يأتي الرد الصوتي من `speechSynthesis` في المتصفحات والأجهزة التي تدعمه. توجد خانة كتابة في القائمة الاحتياطية لفحص parser دون ميكروفون.

أمثلة قابلة للتنفيذ:

- `اغلق إضاءة غرفة النوم` → يطفئ لمبتي الغرفة الرئيسية.
- `خلي شدة إضاءة غرفة النوم 40%` → `setBrightness(40)` على نفس اللمبتين.
- `افتح شتر الغرفة اليمنى` → يفتح W6 وW7.
- `خلي مستوى الستائر 65%` → يفتح جميع الستائر للنسبة المختارة.
- `اقفل ستائر الغرفة اليسرى` → يغلق ستارة W3.
- `وضع الليل للستائر` → يغلق جميع الستائر.

الأوامر غير المعروفة أو نسب خارج 0–100 أو الغرف التي ليس لها الجهاز تُرفض برسالة مفهومة. استخدام الصوت يتوقف على دعم المتصفح وصلاحية الميكروفون، ويُفضّل تشغيل الموقع على HTTPS مثل GitHub Pages. **قد يعالج مزوّد المتصفح الصوت عبر خوادمه**؛ التطبيق لا ينشئ تسجيلًا دائمًا أو يستمع في الخلفية. ليست هناك منظومة فهم أوامر كاملة قائمة على AI؛ توجد قواعد محلية قابلة للتوسعة في `js/voice/voice-control.js`.

## الملفات المعنية

| الملف | الوظيفة |
| --- | --- |
| `js/data/coverings-config.js` | تعريف المواتير والفتحات والغرف والمجموعات |
| `js/devices/coverings/adapter.js` | التسجيل، والتحقق من النسبة، وتحديث الحالة وتخزينها |
| `js/devices/coverings/visuals.js` | إنشاء مجسمات Three.js وتحريكها ومزامنة أيقوناتها فوق الفتحات |
| `js/devices/coverings/controls.js` | قائمة التحكم لكل نوع، وعناصر التحكم الفردي والقوس |
| `js/devices/coverings/automation.js` | الأوضاع الجماعية وجداول التوقيت المحلية |
| `js/voice/voice-control.js` | تحليل الأوامر العربية وتوجيهها إلى السجل دون اعتماد على واجهة المستخدم |
| `js/voice/voice-ui.js`, `js/voice/voice-meter.js` | دورة الاستماع والرد الصوتي وحالات الإعادة، ومؤشر مستوى الصوت
| `styles/coverings.css`, `styles/voice.css`, `styles/transparency.css` | شكل الأقواس والمؤشر الحي والقوائم الشفافة |

لا تضف أي اسم شبكة محلية أو Token أو بيانات دخول أجهزة إلى هذا المشروع المنشور للعامة على GitHub Pages. الربط الحقيقي لاحقًا يتطلب مصادقة، خدمة تحكم داخل شبكة موثوقة، تأكيد استجابة المحرك ومعالجة أوامر الفتح والإغلاق في ظروف الأعطال.

## اختبارات التحقق

```bash
node scripts/check-project.mjs
node scripts/test-devices.mjs
node scripts/test-coverings.mjs
```
