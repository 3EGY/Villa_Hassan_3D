## تحديث v2.9 — إخفاء الأيقونات والشفافية والتحكم الصوتي المباشر

1. فك ضغط **`Villa_Hassan_Smart_Home_v2_9_Transparent_Voice.zip`** وارفَع محتوياته إلى جذر مستودع GitHub Pages **مع الإبقاء على المجلدات**. النسخة لا تحتاج إلى npm أو build.
2. من الأفضل نسخ جميع مجلدات `js/`, `styles/`, `vendor/`, `assets/`, `docs/`, `scripts/` وملفات الجذر معًا، بدل رفع `index.html` منفردًا. امسح كاش المتصفح (`Ctrl+F5`) بعد نجاح النشر.
3. جرّب: اختيار غرفة ثم ظهور أيقونات شتر وستائرها؛ العودة للمخطط العام لإخفائها؛ شفافية قوائم الفتح والإغلاق والقوس؛ الضغط على الميكروفون لظهور النص والصوت المتحرك مباشرة. تأكد من ظهور القائمة الاحتياطية بعد 3 إخفاقات.
4. إعدادات الصوت من «الطبقات والإضاءة»: «إظهار قائمة الأوامر بدل الواجهة الصوتية المباشرة» و«تشغيل رد صوتي من المتصفح». يتم حفظ الخيارين محليًا على المتصفح.
5. التحقق الآلي: `node scripts/check-project.mjs && node scripts/test-devices.mjs && node scripts/test-coverings.mjs`.

**تنبيه:** التعرف على الصوت يتطلب صلاحية الميكروفون، ومتصفحًا يدعم SpeechRecognition، واتصال HTTPS؛ الرد المنطوق يستخدم أصوات نظام التشغيل المتاحة. قد يرسل المتصفح الصوت لمزود الخدمة. لا تستمر الجدولة في حالة إغلاق التبويب، وكل الأوامر لا تزال محاكاة بدون أجهزة فعلية. [تفاصيل الميزات](VOICE_INTERACTION.md).

## تحديث v2.8 — الشتر والستائر والأوامر الصوتية

هذه الحزمة تحافظ على نسخة v2.7 وتضيف **5 شترات، و5 ستائر في 4 مجموعات، وحركة على المجسم وقوس تحديد النسبة وأوضاع النهار/الليل والتوقيت، مع أيقونة ميكروفون**. تعمل كل هذه الأوامر بالمحاكاة في المتصفح فقط. راجع [الأماكن والجدولة والأوامر](COVERINGS_AND_VOICE.md).

1. فك ضغط **`Villa_Hassan_Smart_Home_v2_8_Coverings_Voice.zip`**.
2. انقل **محتويات الحزمة** إلى جذر مستودع GitHub الذي ينشر الموقع، وليس إلى مجلد فرعي جديد. احتفظ بمجلدات `js/` و`styles/` و`assets/` و`vendor/` و`docs/` كما هي.
3. نفّذ `git add . && git commit -m "Add shutters, curtains and voice simulation" && git push origin main` بعد مراجعة التغييرات؛ **لا تستخدم `--force`**.
4. بعد نشر GitHub Pages افتح الموقع وأعد التحميل الكامل `Ctrl+F5`، ثم جرّب: أيقونة شتر عند شباك، القوس بالسحب، الستائر، فتح وإغلاق الكل، الجدولة، والميكروفون أو مربع الأوامر.

قبل النشر تحقّق محليًا:

```powershell
node scripts/check-project.mjs
node scripts/test-devices.mjs
node scripts/test-coverings.mjs
```

بعد بدء الجولة، `VillaDevices.list().length` ينبغي أن يُظهر **24 جهازًا** (14 إضاءة + 5 شتر + 5 ستائر). لا تستمر التوقيتات التلقائية عند غلق الصفحة؛ يعمل الصوت فقط في المتصفحات التي تدعم واجهة التعرف الصوتي ومع السماح بالميكروفون على اتصال آمن. **رابط GitHub Pages الحالي يظل على الإصدار المنشور السابق إلى أن ترفع محتويات هذه الحزمة.**

## التحديث المنظّم — الإصدار 2.6 (مع الحفاظ على مقاسات v2.5)

1. فك ضغط حزمة `Villa_Hassan_Smart_Home_v2_8_Coverings_Voice.zip`.
2. افتح [المستودع](https://github.com/3EGY/Villa_Hassan_3D) ثم **Add file → Upload files**.
3. ارفع **جميع ملفات الحزمة مع الحفاظ على أسماء المجلدات**: `index.html` و`windows-review.html` ومجلدات `js/` و`styles/` و`vendor/` و`assets/`. لا ترفع HTML وحده؛ سيحتاج إلى ملفات JS وCSS المنفصلة.
4. ارفع `README.md` ومجلدي `docs/` و`scripts/` أيضًا لتحديث الشرح والصور والتحقق من المشروع. حافظ على المسارات كما هي.
5. احفظ بـ **Commit changes**، وانتظر نجاح نشر الموقع من **Actions**.

لا تحتاج إلى إعادة إعداد GitHub Pages. بعد اكتمال النشر، حدّث الصفحة بـ `Ctrl + F5` على الكمبيوتر، أو افتح الرابط في تبويب خاص على الهاتف للتأكد من ظهور النسخة الجديدة.

**ما الذي تغير في v2.6؟**

- تقسيم أكواد التطبيق والمكتبات والأنماط إلى ملفات ومجلدات وظيفية، دون تغيير أسلوب التحكم الحالي.
- توحيد بيانات الشبابيك في `js/data/window-config.js`، واستخدام `assets/reference-plan.png` بدل تكرار الصورة.
- توثيق الهيكل وكيفية إضافة الأجهزة الجديدة في [`docs/ARCHITECTURE.md`](ARCHITECTURE.md).

**التغييرات الوظيفية المحتفظ بها من v2.5:**

- دمج W1 وW2 في شباك واحد بعرض 200 سم، وتثبيت مناسيب الجلسات وارتفاعات الفتحات المعتمدة لجميع الشبابيك.

- مراجعة حدود المخطط والأبواب والفرش مع الصورة الأصلية، وتثبيت 6 شبابيك بفتحات فعلية بعد دمج شباكي الرئيسية.
- محرر ارتفاع الجلسة وارتفاع فتحة كل شباك، مع الحفظ المحلي ونسخ المقاسات.
- سرير وتلفزيون في الغرفة اليسرى: التلفزيون على جدار الباب والسرير مقابله.
- سرير وتلفزيون في الغرفة اليمنى: رأس السرير على جدار الباب والتلفزيون مقابله.
- إزالة جدار الدرج المحدد بالكامل، وفتح باب الغرفة اليمنى بعرض 90 سم، وتصحيح فتحة باب الغرفة اليسرى بعرض تقريبي 100 سم وفق الصورة الجديدة.
- ست إضاءات جديدة قابلة لضبط الشدة واللون والمؤقت، تشملها أوضاع الإضاءة العامة. الإجمالي 14 إضاءة.
- اختيارات مستقلة للغرفتين، وجلسة التراس، وحمام الضيوف، والمغاسل، والتراس الأيسر، مع تقريب الكاميرا لكل مكان.
- استمرار إصلاح السحب المتواصل للأقواس على أندرويد من الإصدار 2.2.

وتستمر تحسينات العرض السابقة:

- تصغير أسماء الأماكن وإظهارها مؤقتًا عند لمس المخطط، ثم إخفائها بعد ٣٫٥ ثوانٍ.
- اللمسة الأولى عندما تكون الأسماء مخفية تُظهرها؛ بعدها اختر اسم المكان أو استخدم الشريط السفلي مباشرة.
- تقريب غرفة النوم على الهاتف وفق حدود الغرفة، مع زاوية تستفيد من طول الشاشة.
- عرض أقرب للفيلا كاملة من أعلى، محسوب على المساحة المتاحة فوق الشريط السفلي.
- كل وضع إضاءة، بما فيه إغلاق وتشغيل الكل، يعيد العرض إلى كامل الفيلا ويخفي أيقونات لمبات الغرف.

## أول رفع من Windows PowerShell

يُفترض أن Git مثبت، وأن ملف `Villa_Hassan_Smart_Home_v2_8_Coverings_Voice.zip` موجود في المجلد الحالي، وأن مجلدًا باسم `Villa_Hassan_3D` غير موجود فيه.

```powershell
git clone https://github.com/3EGY/Villa_Hassan_3D.git
Set-Location .\Villa_Hassan_3D
Expand-Archive -LiteralPath ..\Villa_Hassan_Smart_Home_v2_8_Coverings_Voice.zip -DestinationPath . -Force
git add index.html windows-review.html assets docs js styles vendor scripts 404.html .nojekyll .gitignore README.md THIRD_PARTY_NOTICES.md
git commit -m "Publish Villa Hassan interactive 3D presentation"
git branch -M main
git push -u origin main
```

نفّذ الأوامر بالترتيب؛ إذا ظهر خطأ، عالجه قبل الانتقال للأمر التالي. لا تستخدم `--force` للرفع. إذا طلب Git تسجيل الدخول، استخدم حسابًا له صلاحية الكتابة في `3EGY/Villa_Hassan_3D`.

إذا طلب Git تعريف اسم صاحب التعديل والبريد، اضبطهما داخل مجلد المشروع باستخدام بيانات حسابك الفعلية، ثم أعد أمر `git commit`:

```powershell
git config user.name "YOUR_GITHUB_NAME"
git config user.email "YOUR_VERIFIED_OR_NOREPLY_EMAIL"
```

| الإعداد | القيمة |

https://3egy.github.io/Villa_Hassan_3D/

## التحديثات التالية

من داخل مجلد المشروع، اجلب آخر نسخة قبل بدء التعديلات:

```powershell
git pull --ff-only origin main
```

بعد تعديل الملفات وحفظها:

```powershell
git add index.html windows-review.html assets docs js styles vendor scripts 404.html README.md THIRD_PARTY_NOTICES.md .nojekyll .gitignore
git commit -m "Update Villa Hassan presentation"
git push origin main
```

إذا عندك تغييرات محلية غير محفوظة ويعترض `git pull`، احفظها في commit أولًا ثم اجلب التحديثات. لا تتجاوز تعارضات Git باستخدام force push.

## معالجة المشاكل الشائعة

| المشكلة | ما الذي تراجعه؟ |
| --- | --- |
| `git` غير معروف | تثبيت Git for Windows ثم فتح PowerShell من جديد |
| خطأ 403 أثناء الرفع | الحساب المستخدم وصلاحية الكتابة في المستودع |
